# Netflix-cleaning-dataset
This project focuses on cleaning and preparing the Netflix Movies &amp; TV Shows dataset for further data analysis.
🔍 Project Overview

The dataset contains information about movies and TV shows available on Netflix, including titles, directors, cast, countries, release dates, ratings, genres, and durations.

The goal of this project was to transform the raw dataset into a clean and consistent format suitable for analysis and visualization.

🧹 Data Cleaning

The cleaning process included:

Identifying and handling missing values
Removing duplicate records
Standardizing inconsistent data
Cleaning text fields
Formatting dates and other columns
Separating and organizing relevant information
Checking the dataset for inconsistencies
🛠️ Tools Used
MySQL — Data cleaning and transformation
Excel — Initial data inspection and validation
📊 Next Steps

After cleaning, the dataset can be used to explore questions such as:

How has Netflix content changed over time?
Which countries produce the most content?
What are the most common genres?
How does the distribution of movies compare with TV shows?
Which ratings are most common?
🎯 Goal

This project demonstrates practical data-cleaning skills and prepares a real-world dataset for exploratory data analysis.
